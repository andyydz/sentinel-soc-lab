# Security Policy

## Purpose

SENTINEL is an isolated cybersecurity laboratory intended for defensive security research, detection engineering, incident response practice, and controlled adversary simulation.

## Scope

All attacks and testing performed within SENTINEL must remain inside the designated laboratory environment.

The lab uses isolated virtual networking to separate simulated enterprise systems from the host environment.

## Laboratory Safety

- Do not intentionally attack systems outside the laboratory.
- Do not use real credentials or secrets in the lab.
- Do not store personal or sensitive information in the repository.
- Do not commit API keys, passwords, tokens, private keys, or certificates.
- Do not upload virtual machine disks or raw sensitive telemetry.
- Attack simulations should be performed only against systems owned or explicitly authorized for testing.

## Reporting

Security issues affecting the project itself should be documented through the project's issue tracking system or private communication when appropriate.
